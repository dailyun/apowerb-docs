```
Gmail ──push──▶ Google Pub/Sub ──HTTP POST──▶ apowerb
                  (topic)                          /api/webhooks/gmail/notifications
                                                        │
                                                        ▼
                                                  fetch new mail via the Gmail API
                                                        │
                                                        ▼
                                                  run the associated agent
```

## Prerequisites

- A Google Cloud project with billing enabled
- Gmail API, Google Drive API, and Cloud Pub/Sub API enabled
- A publicly reachable HTTPS URL

## Register an Application

To establish the connection, you first need to set up an OAuth application in the [Google Cloud Console](https://console.cloud.google.com/):

<Steps>
  <Step title="Configure OAuth Consent Screen">
    Go to **APIs & Services** > **OAuth consent screen**. Select **External** (or Internal), fill in required fields, and add the [scopes for the services you connect](#oauth-scopes).
  </Step>
  <Step title="Create Credentials">
    Go to **APIs & Services** > **Credentials** > **Create Credentials** > **OAuth client ID**.
    - Type: **Web application**
    - Name: `apowerb-integration`
    - Authorized redirect URIs: `https://your-domain.com/api/v1/auth/callback`
  </Step>
  <Step title="Save Credentials">
    Download the JSON credentials or copy the **Client ID** and **Client Secret**.
  </Step>
</Steps>

## OAuth scopes

Every service requests the identity scopes below, plus its service-specific scopes.
The service bundles are defined in [`GOOGLE_SERVICES`](https://github.com/apowerb/apowerb/blob/main/src/apowerb/integrations/google.py).

| Identity scope | Used for |
| --- | --- |
| `openid` | Authenticate the connected Google account. |
| `email` | Identify the account by its email address. |
| `profile` | Read the account's basic profile information. |

| Service | Scope | Used for |
| --- | --- | --- |
| Drive | `https://www.googleapis.com/auth/drive.readonly` | Read and download files in Google Drive. |
| Gmail | `https://www.googleapis.com/auth/gmail.readonly` | Read email messages and metadata. |
| Gmail | `https://www.googleapis.com/auth/gmail.send` | Send email messages. |
| Calendar | `https://www.googleapis.com/auth/calendar.readonly` | Read calendars and their events. |
| Calendar | `https://www.googleapis.com/auth/calendar.events` | View and edit calendar events. |
| Sheets | `https://www.googleapis.com/auth/spreadsheets` | Read and edit spreadsheets. |
| Docs | `https://www.googleapis.com/auth/documents` | Read and edit documents. |

## Infrastructure Setup

<Steps>
  <Step title="Enable the APIs">
    ```bash
    gcloud services enable gmail.googleapis.com drive.googleapis.com pubsub.googleapis.com \
      --project=YOUR_PROJECT_ID
    ```
  </Step>
  <Step title="Create the topic">
    ```bash
    gcloud pubsub topics create gmail-notifications \
      --project=YOUR_PROJECT_ID
    ```
  </Step>
  <Step title="Permissions">
    ```bash
    gcloud pubsub topics add-iam-policy-binding gmail-notifications \
      --project=YOUR_PROJECT_ID \
      --member="serviceAccount:gmail-api-push@system.gserviceaccount.com" \
      --role="roles/pubsub.publisher"
    ```
  </Step>
  <Step title="Create the push subscription">
    ```bash
    gcloud pubsub subscriptions create gmail-notifications-push \
      --topic=gmail-notifications \
      --push-endpoint=https://YOUR_DOMAIN/api/webhooks/gmail/notifications \
      --project=YOUR_PROJECT_ID
    ```
  </Step>
</Steps>

## Setup

<Steps>
  <Step title="Configure the environment">
    Set the following `GOOGLE_INTEGRATION_*` variables in your environment:
    - `GOOGLE_INTEGRATION_CLIENT_ID`: Your Client ID
    - `GOOGLE_INTEGRATION_CLIENT_SECRET`: Your Client Secret
    - `GMAIL_PUBSUB_PROJECT_ID`: Your GCP project ID
    - `GMAIL_PUBSUB_TOPIC`: `gmail-notifications`
  </Step>
  <Step title="Connect services">
    From the interface, navigate to **Integrations** and select **Google**. Connect your account using the configured credentials.
  </Step>
  <Step title="Subscribe to notifications">
    ```bash
    curl -X POST https://YOUR_DOMAIN/api/webhooks/subscriptions \
      -H "Authorization: Bearer TOKEN" \
      -H "Content-Type: application/json" \
      -d '{
        "provider": "google_gmail",
        "resource": "INBOX",
        "agent_id": "AGENT_ID",
        "change_type": "created"
      }'
    ```
  </Step>
</Steps>
